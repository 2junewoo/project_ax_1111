# 빼빼로 베이스기타 (11.11)

빼빼로데이 기념 3D 프린팅 작품입니다. 하트 모양 바디의 베이스기타에 빼빼로를 꽂아 세울 수 있고, 바디에 "11.11" 글자가 들어갑니다.

Claude Code에서 **Blender MCP**로 Blender를 직접 조작해 모델링하고, STL로 내보내 학교 3D 프린터(Bambu Lab X1C)로 출력했습니다.

## 파일

| 경로 | 내용 |
| --- | --- |
| `pepero.py` | 빼빼로 3종(오리지널·아몬드·화이트 줄무늬) 모델 생성 |
| `bass.py`, `base.py` | 베이스기타 바디·넥, 빼빼로 꽂이 생성 |
| `베이스기타.blend` | Blender 원본 |
| `stl/` | 부품별 STL |
| `assets/` | "11.11" 글자 STL |
| `출력용/` | 실제 출력한 STL과 슬라이스 완료 3MF |
| `docs/session-2026-11-11.jsonl` | Claude Code 작업 대화 기록 (개인정보 가림) |
